# GtaVI-UI

Interfaces web inspirées de GTA VI, en React.

- HUD : minimap, barres de statut, recherche, argent, voyants, fiche d'entrée en véhicule, GPS
- Boussole
- Menu pause
- Garde-robe
- Roulette d'armes
- Fiche véhicule

## Lancer

```
pnpm install
pnpm dev
```

La barre en bas de la page permet de passer d'une interface à l'autre.
